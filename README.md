# zoal-honeycomb (Previously xa-honeycomb)

[User Guide](https://honeycomb.zoal.app/)

> **v2 requires X-Plane 12.4.4 or newer** on Apple Silicon Macs, Windows x64 or Linux x64.
> X-Plane 11 and Intel Macs are no longer supported. Check your X-Plane version (first line of `Log.txt`) before upgrading.
> On an older setup, use [v1.18.0](https://github.com/x-z7a/zoal-honeycomb/releases/tag/v1.18.0) and the [v1 docs](https://honeycomb.zoal.app/v1/).
